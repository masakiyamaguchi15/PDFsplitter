# トラブルシューティング (Troubleshooting)

アプリケーションが正常に動作しない場合や、エラーが発生した場合の主な原因と対処方法を説明します。

---

## よくあるエラーと対処法

### 1. 起動時に「ライブラリがインストールされていません」と表示される

#### 【原因】
本アプリケーションの動作に必要な `PyMuPDF (fitz)` または `Pillow` が実行環境のPythonにインストールされていません。

#### 【対処方法】
エラーメッセージに表示される指示に従い、コマンドプロンプトやターミナルで以下のコマンドを実行してください。
```bash
pip install pymupdf pillow
```
VS CodeやPyCharmなどの統合開発環境（IDE）を使用している場合は、使用している仮想環境（venvやcondaなど）のアクティブなターミナル内で実行しているか確認してください。

---

### 2. Linux環境で起動しようとすると `ModuleNotFoundError: No module named 'tkinter'` が発生する

#### 【原因】
Linuxディストリビューションによっては、Pythonの標準GUIパッケージである `tkinter` がデフォルトで同梱されていない場合があります。

#### 【対処方法】
システムのパッケージマネージャから `tkinter` をインストールする必要があります。

* **Ubuntu / Debian 系の場合**:
  ```bash
  sudo apt-get update
  sudo apt-get install python3-tk
  ```
* **Fedora / RHEL 系の場合**:
  ```bash
  sudo dnf install python3-tkinter
  ```

---

### 3. PDFファイルを開いた際に「PDFファイルを開けませんでした」とエラーダイアログが表示される

#### 【原因】
- 読み込もうとしたPDFファイルが破損している。
- PDFファイルがパスワードで保護（暗号化）されている。
- ファイルへのアクセス権限がない。

#### 【対処方法】
- 他のPDFビューア（Adobe Acrobat Readerやブラウザなど）でそのPDFファイルが開けるか確認してください。
- パスワード保護されているPDFの場合は、あらかじめ保護を解除したPDFを用意して読み込んでください（※本ツールは現在、暗号化解除機能には対応していません）。

---

### 4. ページカードのサムネイルが「Loading...」のまま更新されない、またはエラーが表示される

#### 【原因】
バックグラウンドでのサムネイル画像のレンダリング中に例外が発生した可能性があります。非常に解像度が高い巨大なページや、特殊なフォントが埋め込まれている場合に発生することがあります。

#### 【対処方法】
- アプリケーションを一度閉じて再起動し、再度読み込んでみてください。
- エラーダイアログに表示される詳細なエラーメッセージを確認し、問題のあるPDFファイルであるか確認してください。

---

### 5. マウスホイールによるスクロールが動かない

#### 【原因】
TkinterのCanvasウィジェットへのフォーカスや、表示されているコンテンツ量がウィンドウ高さより少ないことが原因である可能性があります。

#### 【対処方法】
- アプリケーション画面の中央（プレビューエリア）を一度クリックしてフォーカスを当ててからスクロールを試してください。
- ページ数が少なく、全ページが1画面に収まっている状態ではスクロールは機能しません（スクロールする必要がないため正常な挙動です）。
